# Legacy Scripts

This directory contains the pre-binary Pandocker entrypoints.

## Current status

- Windows users should use `pdx.exe` through `install.ps1`.
- The files here are kept for reference and fallback only.
- New work should target the Rust binary under `tools/pdx-win/`.
